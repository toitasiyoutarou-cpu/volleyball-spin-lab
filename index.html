02ボールと区間を指定

動画を選択して、解析を始めましょうまたは合成デモで操作を確認
フレーム —再生位置 —

ボールの中心をタップし、円を外周に合わせます。ドラッグで中心を微調整できます。

開始フレームでボールの位置を保存してください。

同じフレームに候補を何個でも追加できます。新しい候補を使用し、以前の候補は残します。解析に使う円は各フレーム1つです。「使用する」で切り替えられます。

外周が背景と区別しにくい場合は、解析設定の「指定位置の間を補間」を使えます。模様がぼけている・小さすぎる場合は、鮮明な区間または別の元動画が必要です。

撮影のポイント

カメラを固定し、ボールが離れた直後から撮影。明るい場所で短い露光時間を使い、元動画をそのまま読み込んでください。模様の線が鮮明で、直径80px以上が目安です（40px未満は解析を棄却）。

確かめてから使う

周期検証には2回転以上が必要です。単眼・弱透視投影・ほぼ一定の回転を仮定します。基準となる既知の回転や手作業の周期計測と照合し、実写の測定精度を検証してください。

03解析設定

補間では開始と最後に解析するフレームの位置保存が必要です。途中にも位置を指定し、円が外周に合うか確認してください。模様の品質判定は省略しません。

240fps撮影でも、保存された動画が30fpsのスロー動画なら時間の補正が必要です。

動画の読み込みを待っています
時間情報・対応範囲について

MP4/MOVの非断片化動画ではstts・ctts・elstを読み、提示時刻順にフレームを並べます。複数ビデオトラック、複雑な編集リスト、可変速編集、断片化MP4には対応しません。

時刻表を読めない形式では手動FPSでプレビューできますが、研究用の回転数は確定しません。フレームの読み出しはブラウザが担当するため、提示時刻が検証できない場合も結果を保留します。

重複・補間フレームや、保存時に失われたフレームを完全に自動判定することはできません。撮影FPSはコンテナ情報だけでは確定できません。

    解析モデルと3D参考情報

    解析後に表示します。

    正面に見える球面を z = √(1−x²−y²) とし、RGB画像の球面ワープを多段階で当てはめます。小さな並進・拡縮も同時に補正します。位置合わせ残差・観測行列・角速度のばらつき・別のフレーム間隔・自己相関を検査します。

    奥行き成分は球面モデルへの当てはめ値です。カメラ校正、遠近の変化、照明、球の変形を十分には補正していないため、3D計測値としては使用しないでください。奥行き方向に近い軸では2D軸角を表示しません。

    使い方・GitHub公開・検証上の注意
    1. 未編集の動画を選択し、フレーム情報を確認します。
    2. 開始フレームへ移動し、ボールの中心をタップ。直径を外周に合わせて「この位置を候補として追加」を押します。
    3. 開始・終了を設定し、時間変換を確認して解析します。1回の上限は720枚です。
    4. 解析後、フレームを送って追跡円を確認します。停止したらそのフレームで円を修正し「この位置を保存して再開」。同一フレームの候補は保存リストで切り替えられます。問題がなければ追跡確認のチェックを入れます。
    5. 品質条件を満たす結果が表示されます。CSVには無効理由、時間条件、各フレームの追跡情報も記録します。

    iPad Safari：「ファイル」アプリでHTMLをタップするとプレビュー表示になる場合があります。GitHub Pagesにこのファイルを index.html として配置し、Safariで開く方法を推奨します。ページ配信には接続が必要ですが、動画の読み込み・解析に外部通信はありません。オフライン再起動の保証はありません。PCではHTMLをローカルに保存して直接開けます。

    GitHub：新しいリポジトリのルートに index.html を追加 → Settings → Pages → Deploy from a branch → main / (root) → Save。公開するのはHTMLだけで、動画ファイルをリポジトリに追加する必要はありません。

    精度の限界：一般的なバレーボールの似た模様、ぼけ、背景との混同、非球面変形、急な回転変化では誤推定が残ることがあります。棄却判定は誤りを完全に排除しません。実写動画とiPad実機での精度・動作は別途検証が必要です。合成デモの成功を実写の精度保証に使わないでください。

    参照仕様：動画フレーム時刻 / QuickTime stts。参照先はクリックしたときだけ開きます。
